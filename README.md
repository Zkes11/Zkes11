**✅ Proyecto Principal Actual**

Sistema enterprise multi-tenant para gestión automatizada de campañas publicitarias con IA

**Arquitectura:**
- 5 microservicios en Go + 1 servicio Python
- gRPC para comunicación inter-servicios
- PostgreSQL multi-tenant con Row Level Security
- API Gateway con Traefik
- Clean Architecture + Hexagonal

**Características técnicas:**
- 🔐 Autenticación JWT con hardening y seguridad avanzada
- 🎨 Generación de copys e imágenes con IA (OpenAI, Gemini, Claude)
- 📊 Análisis de campañas con workflows Temporal.io
- 🌐 Integración con Meta Ads API (Facebook/Instagram)
- 🏢 Multi-tenancy con aislamiento de datos por empresa
- 📈 Smart image generation con optimización de prompts
- 🔒 Encriptación AWS KMS + S3 para almacenamiento
- ⚡ Circuit breaker, caching con Redis, rate limiting
