### 🤖 Sistema de Campañas IA - Enterprise Multi-Tenant
**✅ Entregado (v1 y v2 funcionales) · Inactivo**

Plataforma enterprise para gestión automatizada de campañas publicitarias con IA (Meta Ads API)

**Arquitectura:**
- 6 microservicios en Go (auth, content, campaign-analyzer, campaign-template, meta-ads, mcp-search) + 1 servicio Python
- gRPC para comunicación inter-servicios
- PostgreSQL multi-tenant con Row Level Security
- API Gateway con Traefik
- Clean Architecture + Hexagonal

**Características técnicas:**
- 🔐 JWT con token blacklist, RBAC (6 roles / 25 permisos)
- 🎨 Generación de copys e imágenes con IA (OpenAI, Gemini, Claude)
- 🌐 Integración con Meta Ads API (Facebook/Instagram)
- 🏢 Multi-tenancy con aislamiento por schema + KMS encryption
- ⚡ Circuit breaker, caching con Redis, rate limiting
